# Inflammation Detector | كاشف الالتهاب في الصور المقطعية

مشروع ذكاء اصطناعي يهدف إلى تصنيف الصور الطبية المقطعية (CT Scan) لتحديد ما إذا كانت هناك علامات التهاب (مثل الالتهاب الرئوي) أو لا، باستخدام تقنيات التعلم العميق (Deep Learning).

## 📌 نظرة عامة
تم تطوير هذا المودل باستخدام الشبكات العصبية التلافيفية (CNN) لتحليل الصور الطبية وتصنيفها بدقة. المشروع مخصص للأغراض التعليمية والبحثية فقط.

## 📊 البيانات (Dataset)
نظراً للحجم الكبير لملفات البيانات، لم يتم رفع الداتاسيت إلى هذا المستودع. يحتوي هذا المستودع على الكود المصدري المستخدم في تدريب المودل.

## 🧠 هيكلية المودل (Model Architecture)
- **النوع:** Convolutional Neural Network (CNN)
-هاب في الصور المقTensorFlow / Keras
-tor | كاشف الالتهلم يتم رفعه إلى المستودع نظراً لحجمه الكبير.
